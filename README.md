# AI-Based Smart Grid Electricity Price Forecasting Using Big Data Analytics
Flask + SQLite + scikit-learn Random Forest regression demo.

Features: home page, registration/login/logout, dashboard, electricity price prediction, saved prediction history, sample forecast-data explorer, and analytics page.

## Run
1. Install Python 3.10+
2. In this folder run `pip install -r requirements.txt`
3. Run `python app.py`
4. Visit http://127.0.0.1:5000

Demo login: `demo@smartgrid.ai` / `GridDemo123!`

## Important
This academic prototype uses synthetic generated data, not a real grid dataset or live market feed. Prices are illustrative and must not be used for real trading or operational decisions. For a genuine big-data project, integrate a documented utility/market dataset, handle time zones and missing values, and evaluate with MAE/RMSE on held-out chronological data.
